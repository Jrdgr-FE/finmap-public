# FinMap 硬科技产业研究版 · 2026-10-23

## 本次实现

以线上 `a210788` 为基线，先合并用户在 10 月 22 日新增的公司与赛道，再扩展研究功能。既有公司 ID、独立地址、融资和事件记录保留。公司库共 221 个主体，其中本轮新增 99 家；12 个赛道、43 个环节，目前 41 个环节有样本。覆盖国内与海外，包括初创项目、产业锚点和集团业务部门，不宣称全行业公司已收齐。

- `/ventures/`：产业链矩阵、赛道/地区/关键词/环节筛选、公司列表、当前结果 CSV 导出；支持 URL 保存筛选。
- `/ventures/<track>/`：赛道环节及公司档案入口；一个公司允许多个产业位置。
- `/venture/<id>/`：业务、官网、来源、产业位置、同环节公司、8 条有公告日期的公司关系、公开新闻与原有事件时间线。
- `/ventures/news/`：公开新闻归档、按公司和关键词过滤、分批展示。
- `/ventures/coverage/`：逐环节数量、空白与口径、新闻初始回溯不足及后续潜在历史缺口。

研究资料见 `data/ventures/ai-hardware.yaml`、`broad-hardtech.yaml`。既有公司官网资料通过 `*-enrichment.json` 白名单补充，不覆盖名称、简介、估值和历史事件。公司关系只接受明确来源，不因产业环节相邻而创建供货边。融资估值仍保留原币种、时点和原报道状态。

## 公开新闻边界

生成器 `npm run ventures:news` 只访问 FinHot 公共文章接口与已验证官方 RSS（NVIDIA、OpenAI、Google DeepMind），不连接私有数据库。最初有限窗口导入约 481 条新闻，关联 18 家公司；每轮变化以 `data/news/metadata.json` 为准。FinHot 公开接口当时仍为金融域，这使新增硬科技公司的新闻覆盖不均衡。

三种归档方式分别呈现：标题提及、仅摘要提及、公司自有官方渠道。自动匹配是研究线索，不会自动转成已确认融资、订单或供货事件。常见词、函数名称、产品名称与公司名分开处理；严格 `match` 会替代默认名称列表。审查覆盖 Intuitive、Modal、Claude、阶跃、MiniMax、WHOOP、Cohere、ABB、Ouster、Xanadu、Fourier、Lambda 等误报。

输出只含公开允许字段。官方 RSS 保留标题/链接/日期，不复制全文。RSS 归属校验、URL 协议与凭据检查、DOCTYPE/外部实体拒绝、显式 private/public:false 排除已测试。转载去重保留原官方渠道归属。

- `data/news/public-history.json`：已公开材料的允许字段历史，供新增公司重新匹配；不发布为站点文件。
- `public/data/venture-news.json`：匹配后的公开归档与关联理由，作为静态内容构建。
- `data/news/metadata.json`：抓取窗口、每个来源状态、历史缺口与数量。
- `data/news/exclusions.json`：误匹配/需撤回文章 ID 排除清单。
- 原 `data/ventures/candidates.json` 是未审内部线索，仍被 gitignore，不能进入公开生成器。

保留 180 天、最多 20,000 条；容量有限时优先保留已关联公司的材料。FinHot 每次最多 50 页 × 20 条，后续读取与前次成功时点重叠 48 小时。首次截断持久标记“初始历史未回溯”；中断导致新旧窗口无交集时持久记录潜在缺口，而不假称连续完整。按原文链接/文章标识去重。此窗口并不等于完成 180 天历史回填。

## 自动更新与成本

沿用已有 Cloudflare Pages 项目 `finmap` 和 GitHub Actions 发布链路，无新增数据库或云主机。

`.github/workflows/deploy.yml` 在 main 推送、手动执行和每 6 小时（UTC 00:23/06:23/12:23/18:23）运行。步骤为依赖安装、离线测试、公开新闻更新、数据校验、类型检查、静态构建、仅提交三个指定公开归档文件、部署 Pages。GitHub 调度可能延迟，不能承诺整点实时更新；页面显示实际成功时间。

Cloudflare 部署密钥只在发布步骤注入。部分来源失败保留该源历史，标记 degraded 并产生 Actions 警告；全部失败或数据不合规时任务失败，线上维持上一版。用户访问公司/图谱/新闻页面只读静态文件，不触发模型、采集或 D1 查询。没有新增付费模型调用或调整 FinHot 的模型预算。

## 验证与回退

- `npm run test:ventures`：27 项离线回归（实体匹配、来源归属、去重、容量、日期、URL、私有字段、故障、关系和补充资料等）。
- `npm run validate`：金融机构及硬科技公司/关系完整性。
- `npm run check`：0 errors；修正原有虚拟根节点 `stakeUndated` 默认值，未改变真实股权数据。
- `npm run build`：5,215 个静态页面。
- 浏览器核对桌面与手机宽度、关键词/地区/赛道组合、空结果、导出 CSV、公司页、新闻搜索和分页；浏览器 CSV 实测为所选半导体 14 家且每行附来源。


## 仍未完成的覆盖

没有完成全球硬科技的普查，也未系统校核每个品牌的工商主体、当前融资阶段、投资可进入性和完整客户供应商关系。两类环节尚缺样本，若干环节仅有少量公司。新闻覆盖集中于已接入来源，早期非上市公司、国内官方公众号和未公开进展通常仍需研究员补证。Tesla/Optimus 等已知缺口没有用未经核实的记录占位；后续应以公司为主体、产品为别名并附来源补齐。

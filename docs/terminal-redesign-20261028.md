# 投研终端界面改版 · 2026-10-28

用户指定 Alpha 派、AlphaEngine、TradingView 作为视觉参考。先检查公开界面与产品截图，再整理 [设计规范](../DESIGN.md)。AlphaEngine 当前入口要求登录；没有把官网介绍或历史截图当作当前完整登录版。

## 已实现

- 全站统一 48 px 深蓝顶栏、76 px 桌面导航、白色 / 深色内容面板、蓝色交互和细分隔线。公司库、公司档案、产业图谱、专题及资料页共用视觉体系。
- 动态首页压缩标题、统计与筛选区；桌面采用可分别滚动的连续列表和右侧区域，避免每次阅读都遮住列表。
- 1101 px 起，详情以内嵌非模态阅读栏打开。选中行高亮并随连续阅读保持可见；上一条 / 下一条沿当前页结果顺序工作。在筛选结果外的旧详情禁用这两个按钮。
- 手机及窄屏继续使用原生模态详情。跨断点时保留当前事件与链接，关闭后清理事件参数并返回原列表焦点；Esc 支持桌面阅读栏，模态继续使用浏览器原生行为。
- 关注清单展示真实公司名和当前范围的动态数；无关注时提供公司库入口。不增加虚假价格、收益、估值曲线或尚未实现的 AI 入口。
- 既有来源状态、弱网提示、重试、个人状态和本地备份协议继续可用。本次未更改服务器采集、公开事件数据或费用设置。

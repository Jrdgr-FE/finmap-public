# 灵巧操作专题与公司补录

2026-10-23

本轮在原有公司库上补充 26 个公开主体档案，涵盖手部产品、微型驱动、关节、触觉、精密制造、算力优化与数据工具。6 个既有公司补充公开资料与跨环节身份，沿用原公司 ID。`verifiedAt` 是本轮公开资料核验日，不是融资、产品发布或交付日期，也不表示历史档案中的每个数字已经重新核验。

专题入口 `/ventures/dexterity/` 将公司分为六个研究角色，使用 `data/topics/dexterity.json` 独立管理。每条角色和产品记录都要求公开来源及核验日，`src/lib/dexterity.ts` 校验公司引用、产品去重、日期和来源。公司相邻排列不构成交易关系。

产品对照先整理五款具体型号，保留主动自由度与关节数、手掌/裸手/整备/含前臂重量、传感配置与软件条件。舞肌采用 Hand 2.2 Beta 非触觉版文档并标明主站版本差异；Shadow 旧 PDF 与当前网页的配置口径分别注明。它们都是厂商公开资料，尚未进行统一条件下的独立测试。

角色名单超过五家时渐进式折叠，禁用 JavaScript 仍能阅读全量。产品表支持关键词搜索，移动端显示产品卡。总图谱搜索纳入事件标题和专题产品型号，新闻匹配仍使用另行审核的保守词表，避免 `DAS Controller`、`Apex Hand` 等通用词误匹配。

## 覆盖边界

- 本专题是已核对样本，不能据此宣称全球公司或参数全部覆盖。
- 手本体与工业夹爪分清角色，仿生义肢公司的机器人产品线单独说明。
- 没有准确主体及一手产品资料的候选不公开建档。
- 同构设备、采集服务、数据销售、模型训练和交付分开记录，未经披露的供应关系不自动连线。
- 当前自动新闻来源主要是 FinHot 的有限公开窗口及三家通用 AI 官方 RSS；机器人部件公司仍有明显信源缺口，专题逐公司显示已整理事件与自动新闻数量。
- 没有新增数据库或模型调用；公开读者继续访问静态页面。

公司公开证据见 `data/ventures/dexterous-hands.yaml`、`robot-supply-chain.yaml`、`compute-data-tools.yaml`、`dexterous-enrichment.json`；参数证据见 `data/topics/dexterity.json`。公开文件仅保存已独立核验的公开内容。

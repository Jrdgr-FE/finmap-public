# FinMap 研究工作台

本轮把入口组织为「动态收件箱 → 关注公司 → 公司档案 → 产业位置」。日常使用围绕公司持续跟进，金融机构资料保留在折叠导航中。

## 产品结构

- `/`、`/ventures/updates/`：统一的动态收件箱。默认最近 7 天，融资、产品与技术、灵巧手三个快捷视图，赛道、环节、地区、公司筛选逐步展开。
- `/?scope=watching`：本机关注公司的动态。`/?scope=saved`：默认显示全部已收录时段，避免旧收藏被最近 7 天隐藏。
- `/companies/`：独立公司库，按赛道、地区、关键词筛选、关注及导出当前结果。最新动态来自已有监测索引。
- `/venture/:id/`：关注入口、动态阅读、产业位置、产品技术和公开来源形成一份公司档案。移除与实时监测不一致的旧新闻总数。
- `/ventures/`：产业位置列与公司卡片，保留筛选、跨环节高亮、名录视图及 CSV。速览使用原生模态框，可关注公司或进入动态。
- `/ventures/dexterity/`：保留代表型号对照与证据，增加专题动态入口。
- `/ventures/monitoring/`：保留真实来源失败、检查时间与覆盖缺口。监测数字不再占据动态首页的主位置。
- `/guide/`：解释研究流程、来源可信层级和当前覆盖边界。

## 视觉与交互约定

固定深色研究导航，浅色内容底、白色内容面板和克制的紫色操作强调。公司缩写与来源标识承担识别功能，不以随机图形表示未经证实的关系。动态分布与近期动态较多的公司均来自当前筛选范围，不能解释为投资排名。

标题打开右侧阅读栏，保留原文链接、发布时间、首次收录、更新版本、归属与证据说明。打开详情标为已读；同一事件有新版本仍可重新成为未读。收藏和关注保留键盘焦点，关闭阅读栏返回原来的标题。手机使用可收起导航和全宽阅读栏，保留深色模式。

沿用 `finmap-monitor-preferences-v1`，不清空既有关注、收藏和阅读记录。状态保存在当前浏览器；存储写入失败时保留本页内存状态并给出反馈。未实现账号、跨设备同步或邮件推送，不展示相应虚假入口。

## 验收与发布

本地浏览器检查：动态筛选、阅读/收藏/关注、公司库搜索、公司档案状态、图谱速览、专题 3/5 型号切换和全站搜索；手机 375px 与桌面 1280px 布局及深色模式。截图保存在被忽略的 `.data/verification/redesign-20261026/`。

现有 49 项业务测试通过；新增 3 项 UI 状态回归覆盖旧记录兼容、写入失败以及其他标签页更新。部署工作流同时执行两组测试、数据校验、类型检查和静态构建。

本轮不修改采集器、自动检查频率或公开事件事实。检索线索仍未逐篇核验全文，X 与公众号仍非完整自动覆盖，公开快照的 5,000 条上限不变。
